# core

Requires [Bun](https://bun.sh/) 1.3.14 or later. See the [OpenTUI runtime support documentation](https://opentui.com/docs/getting-started/runtime-support/) for platform requirements.

To install dependencies:

```bash
bun install
```

To run:

```bash
bun dev
```

To typecheck:

```bash
bun run typecheck
```

This project was created using `bun create tui`. [create-tui](https://github.com/msmps/create-tui) is the easiest way to get started with OpenTUI.
